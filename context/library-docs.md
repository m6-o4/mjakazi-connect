# Library Docs

## Purpose
Project-specific rules and notes for third-party libraries used in this project
that don't already have a dedicated skill (e.g. no `/shadcn` or `/payload`
equivalent covers them). Read this before using any such library, and before
using any Next.js API not already documented here — check
`node_modules/next/dist/docs/` for deprecation notices first.

## How to Use
- **Before adding/using a library**: check if a skill covers it first (see
  AGENTS.md's Available Skills list). If not, check this file for existing
  notes. If nothing exists yet, research the library's current docs before
  writing code against it, then add an entry here.

## Library Entry Format

### `library-name`
- **Version**: [installed version]
- **Why we use it**: [purpose in this project]
- **Gotchas / deprecated patterns to avoid**: ...
- **Project-specific config/usage rules**: ...
