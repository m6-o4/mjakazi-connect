# Build Plan

## Purpose
The ordered roadmap/backlog of features and phases for the whole project. Read
this before starting any new feature to understand what's next and how it fits
into the overall sequence. Update it as features are added, reprioritized, or
completed.

## How to Use
- **Before starting a feature**: confirm it's next in the plan (or note if
  you're deviating from the plan and why).
- **When scope changes**: update this file to reflect the new plan.
- Use `/architect` to think through a feature before adding/refining its entry
  here.
